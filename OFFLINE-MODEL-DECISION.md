# Offline meal photo model decision — refreshed October 24, 2026

The Challenge candidate must stay fully offline and below the size limit in Apple's currently published [2026 terms](https://developer.apple.com/swift-student-challenge/policy/). A food name from a photo is a clue to confirm, never a source for recipe, portion, carbohydrate grams, or insulin units. We will not ship a model solely because it recognizes the three bundled examples.

The current candidate is **1.0 (6)**: 12,203,935 bytes, SHA-256 `774e37b26a642d8d9a08e0e292d868d1ee0b2aca5de47febb9f02d9d89c2856b`. Build 6 changes photo-loading token checks and loading-text foreground styles, with no model, engine or prompt change. The model decisions and earlier processing diagnostics below retain their original scope; the latest [delivery receipt](research/photo-loading/delivery-20261024.json) owns build-6 package/runtime/upload evidence.

## Neutral-eligibility proposal rejected

The [later fixed prompt-text proposal](research/foundation-models/neutral-eligibility-20261024.md) removed meal-presupposing framing while retaining the existing schema/runtime/model. It was longer, not a simplification. One separate call on each exposed P01–P12 image completed with zero amounts/totals; independent verification passed 30 mechanical checks. The fixed adoption gate failed: uncertain P07 returned `brown dessert` instead of inspected-empty. The P02 object clue became empty and P05 had a broader appearance-fit name, but P04 lost useful broad wording and P08 added unsupported garlic/recipe specificity. Do not infer hidden ingredients are absent or that a regional recipe is impossible from these judgments. All exact lists and qualified comparisons are retained.

**Decision:** do not apply this candidate. Current source model `143feea0…`, exact build-6 ZIP `774e37b2…` and internal-testing state are unchanged. Eight separately collected/pixel-reviewed inputs remain unrun. A richer typed abstention result is only an unimplemented structural possibility; it cannot guarantee semantic correctness. Investigate general decision architecture and supported local capabilities before another frozen proposal, preserving unfamiliar foods and broad useful clues. Do not fit object-word blacklists, replace failed cases or claim worldwide/qualified accuracy, physical offline use or readiness from these mechanics.
