## Limits and next evidence

The helper substitutes MainActor classes and computed shared-parent bindings for SwiftUI `@State` storage and manually invokes the extracted disappearance body. Only an outer Task-handle capture changes the loading method; its Task expression and closure are identical. This supports the one-line source guard for that contract; actual state capture/retention/lifetime and navigation behavior remain open.

`onDisappear` may also occur around full-screen camera presentation; existing analysis cancellation already uses it. Camera authorization, presentation, dismissal and capture ordering were not tested. Newer-entry snapshot comparisons include shared-parent fields and do not prove that an old task changed the newer entry's local busy/token state.

Token invalidation does not cancel the Task or interrupt an active transfer/preparation, prove OS compute release, or improve measured memory. This is separate from the earlier [36 loading-method checks](README.md). No real picker/decoder/model, actual app UI/accessibility, physical/network-isolated offline, package, build delivery or upload gate closes here. A separate no-model SwiftUI lifecycle check is still needed.
